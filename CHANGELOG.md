# Changelog

All notable changes to this project are documented here.

## 1.0.0 — 2026-08-15

### Added

- `obsidian-ahmed-plugin` umbrella identity with the display name **Ahmed's Obsidian Tools**.
- Project Task Capture as the initial isolated feature.
- Mobile-compatible `project-task-add` Markdown action block.
- Project-aware command-palette action.
- Atomic insertion into a configured Markdown Kanban lane.
- Native Obsidian project-link generation.
- Fail-closed checks for missing projects, boards, and ambiguous lanes.
- LF and CRLF preservation.
- Behavioral tests with fake Obsidian infrastructure.
- Repository packaging compatible with the intended three-file BRAT release.
